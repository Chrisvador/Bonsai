# Mes bonsaïs

Application web installable (iPhone, iPad, ordinateur) pour suivre une collection de bonsaïs : fiche par arbre (acquisition, âge estimé, origine, abri l'hiver), travaux datés (rempotage, taille, autre), photos depuis la photothèque, et filtre « Rempotage à prévoir ».

Données et photos dans Supabase (tables `bonsais`, `travaux`, `bonsai_photos`, stockage privé `bonsai`), chaque compte ne voit que ses arbres. Import des photos depuis un export Bonsai Album (`.bdbi`) dans le menu Compte.
